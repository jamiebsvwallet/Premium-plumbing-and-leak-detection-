# 3D Models Directory

This directory should contain 3D models for the digital twin and AR diagnostics features.

## Supported Formats

- **glTF/GLB**: For WebXR and Three.js (preferred)
- **USDZ**: For iOS AR Quick Look
- **FBX/OBJ**: Legacy formats (can be converted to glTF)

## Example Models

For the MVP, you can use free models from:
- [Sketchfab](https://sketchfab.com/feed) (with appropriate licenses)
- [Poly Haven](https://polyhaven.com/)
- [Three.js Examples](https://threejs.org/examples/)

## Creating Custom Models

Use tools like:
- Blender (free, open-source)
- Maya
- 3ds Max

Export as glTF 2.0 for best compatibility.
