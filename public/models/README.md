# Placeholder for 3D Model

This directory contains 3D models for AR/VR visualization.

## Files needed:

- `device-model.glb` - glTF binary format for Three.js
- `device-model.usdz` - USDZ format for iOS Quick Look AR

## Creating models:

Use Blender or other 3D software to create device models and export in these formats.

For testing, you can download sample models from:
- https://github.com/KhronosGroup/glTF-Sample-Models
- https://developer.apple.com/augmented-reality/quick-look/
