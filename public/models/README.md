# USDZ Model Placeholder

This file is a placeholder for a USDZ model for iOS Quick Look AR.

To add a real USDZ model:
1. Export your 3D model from Blender, Maya, or other 3D software
2. Convert to USDZ format using Apple's tools
3. Place the .usdz file here: public/models/device-model.usdz

For now, this serves as a reference point in the file structure.
